# Component images

- All images except `header-connector.webp` come from the club folder
  "صور القطع مع الاسماء" (resized and re-encoded as WEBP for the web).
- Some photos are reused for closely related parts (e.g. the TO-92 package photo
  for 2N2222A / BC516 / 2N2907A / MCP9700, the IC photo for NE555 / LD33CV / L9110H).
  Admins can replace any picture from the inventory screen.
