# Lujain Alasiri

## المهمة
تطوير واجهة إدارة مخزون النادي والطلبات وعهدة الفرق للهاكاثون.

## ملخص العمل
- بناء لوحة عربية متجاوبة بتصميم pixel-art، تشمل مؤقّت الهاكاثون وكتالوج القطع.
- ربط عرض العهدة بالطلبات الموافق عليها، مع السماح بطلب معتمد واحد للفريق وإتاحة إعادة الطلب بعد الرفض.
- إضافة سير عمل لإعادة القطع يتطلب تأكيد المشرف قبل إرجاعها إلى المخزون.
- وضع الواجهة في `Frontend` على فرع مستقل؛ لم تُعدّل ملفات `Backend`.

## التشغيل
من مجلد `Frontend`:

```bash
npm install
npm run dev
```

للتحقق من بناء الإنتاج:

```bash
npm run build
```
